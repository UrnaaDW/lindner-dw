# Lindner Mongolia Website

Доечевэллэ ХХК — Lindner Group-ийн Монгол дахь албан ёсны төлөөлөгч.

## Deploy

GitHub Actions ашиглан `main` branch руу push хийхэд автоматаар GitHub Pages руу deploy хийгдэнэ.

Live site: `https://urnaadw.github.io/lindner-dw/`

## Local dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
